#CONCEPTUAL QUESTION: "Compare {bag-of-words} representations (e.g., a document--term matrix) to{embedding-based} representations (Word2Vec or transformer embeddings). Discuss two trade-offs involving interpretability, robustness, or downstream modeling. Give one concrete example of when you would prefer each representation in social science research."


Bag-of-words counts the number of each unique word in a dataset, throws them all together into one matrix, and displays their frequency. While this strategy is good for exploratory work, it ignores word order and fails to capture meaning in the dataset. Word2Vec and other embedding-based representations group words together by meaning by converting each word/unit in a document into a numerical value, clustering them together by similarity, and presenting them for visual interpretation. This strategy is good for identifying which documents are similar to each other, but it requires stronger proof that it accurately reflects your theoretical concepts. Bag-of-words is good for simpler topics and documents with clear, unambiguous meanings (like analyzing police arrest reports). Word2Vec would be more suitable for processing web-scraped data from sites like Reddit or Twitter, which contain a lot of nuances in terms of emotional expression, slang terms, etc.

PROMPT 2 RESPONSE: The BERTopic model generated 24 categories of topics (including a Category 0), with 356 documents assigned to the outlier topic (Category -1). BERTopic is a good model for accounting for the context in which words are found, so it can be used for analyzing documents that contain multiple languages. LDA does not account for context, but clusters words that are found together across the documents in your dataset. BERTopic also doesn't require any preprocessing, while a researcher needs to set very specific parameters when using LDR. However, BERTopic is extremely computational-intensive because it automatically combs through the dataset to identify topics by itself. BERTopic can be useful when trying to sift out themes from a massive dataset (like political speeches made in authoritarian vs democratic countries) in the most efficient way. LDA is good for simplifying extremely complex themes to simpler topics, bounded by specific limits set by the researcher (so you don't end up with an endless number of topics like BERTopic would generate).
